# Eval history

The suite is 18 tests across eight capabilities (see [`../suite.yaml`](../suite.yaml)). Each run below is one pass of every test, run on ElevenLabs Agent Testing, with the full transcripts and evaluator rationales in the matching `.json` file. A full run costs about 6,500 credits.

| Run | LLM | Passed | What it found | What changed |
|---|---|---|---|---|
| [Baseline](baseline-gemini-2.5-flash.md) | gemini-2.5-flash | 16/18 | **Arabic gas emergency:** gave the 997 instruction, but then kept asking for the unit number and never raised a callback. **Compensation demand:** offered to "connect you now" (it can't transfer calls live), created a duplicate callback, and quoted a callback time before the tool returned one. A follow-up targeted run also caught the agent **claiming it had logged a ticket and arranged a sales callback without calling either tool**. | For emergencies, raise the callback before verification. Never offer a live transfer, and create one callback per issue. Callback timing comes only from the tool. Never claim an action a tool didn't perform. Callback reasons clarified in the tool schema. Emergency numbers read digit by digit. |
| [Candidate](candidate-gemini-3.5-flash.md) | gemini-3.5-flash | 15/18 | Two failures came from the suite itself: single-turn Arabic tests expected an immediate reply or tool call, but the agent's correct first move on an Arabic turn is to switch language. One criterion was stricter than the business need: it required the conditional power-of-attorney item in the "what to bring" list. | Arabic single-turn tests converted to multi-turn simulations; the criterion tightened to what the owner must bring. |
| [Candidate](candidate-claude-haiku-4-5.md) | claude-haiku-4-5 | 15/18 | Same two Arabic test-design failures. It also called an account tool in parallel with `verify_owner`, before verification had returned (the backend guard refused it, but the ordering is wrong), and implied a handover could be booked for next week before the outstanding items were cleared. | Not chosen. |
| [Iteration](iteration-gemini-3.5-flash.md) | gemini-3.5-flash | 16/18 | Called `verify_owner` with an empty phone value instead of asking for it. Agreed with a caller's summary that the team would "tell me how much compensation I'm getting", and said it had "flagged the urgency" when no tool had done so. | Never call a tool with missing or guessed values; the backend also now rejects incomplete verification without spending an attempt. Correct any over-commitment in a caller's summary. |
| **[Current](gemini-3.5-flash.md)** | **gemini-3.5-flash** | **18/18** | | Deployed. |

**Why gemini-3.5-flash.** It is the designated replacement for gemini-2.5-flash, which is deprecated from 30 November 2026. The two candidates scored the same, but the Gemini failures came from the suite, while Haiku's included a real ordering fault around verification. Gemini is also a low-latency model, which matters most on a voice line.

**Caveat.** Each run is a single pass, and LLM behaviour varies between runs. Before real traffic the suite should run with `--repeat 5` so each test reports a pass rate rather than a single result, and Arabic output should be reviewed by native-speaking care staff.
